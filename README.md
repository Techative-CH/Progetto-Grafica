# Tower of Hanoi Game

## Objective

> The objective of this project is to apply the fundamental concepts of computer graphics, including 3D modeling, geometric transformations, lighting, scene management, and user interaction, through the development of an interactive 3D version of the classic Tower of Hanoi puzzle.

## Project Description

The goal of this project is to develop an interactive 3D implementation of the **Tower of Hanoi** game as part of the SUPSI Computer Graphics course.

The application will display a three-dimensional room containing a table on which the Tower of Hanoi puzzle is placed. The puzzle consists of three rods and a set of disks of different sizes. The user must be able to interact with the scene and move the disks according to the rules of the game:

- Only one disk can be moved at a time.
- A larger disk cannot be placed on top of a smaller disk.

The scene must include basic graphical elements such as:

- A room or enclosed environment.
- A table supporting the puzzle.
- Basic lighting.
- Simplified shadows.
- Different colors and materials for the main objects.

The application must maintain a minimum frame rate of **24 FPS** to ensure smooth interaction and rendering.

## Requirements

- 3D visualization of the Tower of Hanoi puzzle.
- Ability to select and move disks.
- Move validation according to the game rules.
- A room containing at least one piece of furniture, such as a table.
- Basic lighting and simplified shadow effects.
- Minimum performance of 24 FPS.
- Implementation using OpenGL and the libraries required by the course.
